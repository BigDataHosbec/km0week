No tengo la clave

Pídesela a Jorge. Si eres Jorge y la has perdido, se crea otra en cuatro minutos:

  1. En GitHub: foto de perfil → Settings → abajo del todo Developer settings.
  2. Personal access tokens → Fine-grained tokens → Generate new token.
  3. En Repository access, marca Only select repositories y elige BigDataHosbec/km0week.
  4. En Repository permissions, pon Contents en Read and write. Si además pones Actions en Read-only, el panel te enseña arriba si la web ha terminado de publicarse. Nada más.
  5. Genera, copia la tira que empieza por github_pat_ y pégala arriba.
